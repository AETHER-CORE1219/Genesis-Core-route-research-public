# 社会的発現経路・外部要因頑健性研究 v7

## 結論

固定済みdevelopment420について、占星術側の連鎖群と五つの社会機能の関連を、年代、現実資料の測定形態、収集元の順に一つずつ調整しました。五機能すべてで正の関連が残り、年代層別、主要な二測定形態、収集元を一つずつ除いた解析、311名・109名それぞれの観測機会調整でも方向は正でした。

さらに、五候補だけでなく事前固定した22面（18面が推定可能、4面は該当者0）を同時に扱う9,999回のperson-package maxT検定を行いました。五機能はすべて同時補正後も正でした。

この結果から言える最大限の主張は、次です。

> 固定development420と固定22面の範囲では、五つの集約社会機能とチャート連鎖群の関連は、測定済みの年代・資料形態・収集元だけでは説明されず、宣言した同時nullの偶然だけでも説明しにくい。

これは、以前の「基礎率より高い」という記述から明確に進んだ結果です。一方、同じ420名は候補発見に関与したdevelopment資料なので、独立人物外再現や因果証明とは呼びません。

## 何を一つずつ検査したか

1. `M0`: チャート連鎖群への該当だけ。
2. `M1`: 年代を追加。
3. `M2`: 現実資料の測定形態を追加。
4. `M3`: 収集元を追加。
5. 第二検証: 年代内置換、収集元内置換、年代層別、主要測定形態別、収集元一つ抜き、311名・109名の観測機会調整。
6. 選択対策: 固定22面を一括したmaxT。
7. 代替説明: 7,634件の既存adversarial decoy、Western/Jyotish片側比較、未測定交絡感度。

職業や分野は候補の入口に使っていません。一人が複数機能を持てる意味構造を維持し、職業・分野は発現媒体、共変量、moderator、transport境界に限定しています。

## 経路の意味

このv7が検査したのは個別の職業ラベルでも、515個すべての個別規則でもありません。検査単位は、占星術側の意味核・担い手・関係・carrierが集約社会機能へつながる固定連鎖群です。個人では全図の別の枝やmodifierが具体的な表現を変えるため、五機能は非排他的です。

## 重要な境界

- `maxT`は固定22面の同時偶然性を扱います。22面を固定する以前の741/515/136候補形成に残る自由度をすべて消すものではありません。
- decoyは結果から選ばれた弱い・逆向きの対照で、ランダムnullではありません。通過は特異性の必要条件であり、偶然性の主根拠はmaxTです。
- Western/Jyotish片側比較はcarrierの記述です。「両体系の相乗効果」を形式検定したものではありません。
- 固定資料に記録された本人行為を測っています。人物の全人生や未来を測ってはいません。
- 公開v3～v5の人物外非陽性結果は不変です。v7はそれらを救済せず、development420内で外部要因・選択偶然性への耐性を追加しました。
