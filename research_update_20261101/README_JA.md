## 1. 原研究の中心質問、合流構造、および人口層

本プロジェクトは、古典的占星術の伝統に関して次の実証的問いを探求しています。  
**「占星術の出生図構造は、人間の社会的発現について、偶然、職業名、資料量、時代差だけでは説明し切れない、反復可能で検査可能な対応構造を持つか」**

本研究は、複数の異なる占星術的実現条件が、現実における同じ上位の社会活動機能へ合流して対応するかどうかを発見・検査する試みです。出生情報が公開されている著名人物の資料を用い（資料の証明水準は歴史的人物の間で一様ではありませんが）、出生図を見ないブラインド状態で、人生における具体的かつ多面的な行為・成果を複数の領域に分類・整理しました。西洋占星術とインド占星術（Jyotish）を別々の並行する象徴体系として構築し、役割（role actor）、能力（connected capability）、意味関係（semantic relation）、実現条件（realization condition）からなる複合的な規則が、客観的な社会活動とどのように対応するかを追跡しています。

本研究のデータ人口は、分析上の役割が異なる複数の層から構成されており、これらを単純に合算してはなりません：
- **上流資料レコード数：1,030件**
- **名義整理後の人物数：793名**（出生記録795件から既知の別名2件を区別）
- **発見・活動資料面：731名**
- **共通開発コホート：420名**（詳細な引用資料を持つ311名群と、当初要約的アンカーから整理され、今回保存本文への接続が復元された109名群）

現実側の11の活動機能から反復する条件を探索し、抽出された741規則のうち、五つの広い社会的機能に関係する515規則が主要な分析対象の候補群として同定されました。五機能とは、*公的働きかけ*（Public Advocacy）、*著作・象徴制作*（Authored and Symbolic Production）、*集団実現*（Organized Collective Realization）、*技術・製品実装*（Technical and Product Implementation）、*身体的遂行*（Embodied Performance：競技スポーツに限定されず、実験的操縦、宇宙探索、身体的ナビゲーション等を含む）です。1人の人物は複数の活動領域を持ち、上位の単一機能に対しても複数の異なる実現条件が接続します。

歴史的v7版では、開発420名において五機能で+27.95〜+39.08パーセントポイントの調整後出現差が報告されました。これに先立つ研究史の初期段階（v3〜v5）において、開発コホート外の人物を対象に特定の分岐に絞って実施された3回の限定検査では、肯定的な確認は得られませんでした。これらの過去の限定的な非陽性結果をもって全機能や占星術体系全体の否定へと過剰一般化することはせず、現時点において人物外での実証、因果関係の確立、あるいは個人予測の成立を主張するものではありません。

## 2. 象徴意味の保持とグラフトポロジーの厳密化

今回の研究更新では、計算体系の再構築を進める過程において、原研究が捉えていた象徴的な意味構造が損なわれずに保たれているかを厳密に検証することが不可欠となります。この検証の客観的な前提として、まず旧AITグラフおよび741規則の応答を420名全員について完全再現しました。

五機能515規則における公開版AIZと可搬版AJYの差は416/420名に及び、可搬表現のままでの出生入力訂正による差は55/420名でした（全741規則ではそれぞれ417名、56名）。

身体的遂行において両体系の複合条件を満たす人数は、保存版の変遷順に 25 → 1 → 0 → 0（旧AIT、役割・関係修正版AJH、yoga網羅版AJY、入力訂正版AJY）と推移しました。この変化は単なる出生時刻の訂正によるものではなく、構造の曖昧さの解消に起因しています：
1. **プレースホルダー記録の証拠化**：関係証拠が文字列 `__MISSING__` のみであったリンクを除外する診断テストでは、該当人数が25名から12名へと変化しました（時系列の中間版ではなく、AITコピーを用いた独立した診断）。
2. **グラフトポロジーの厳密化**：旧モデルでは、流入ディスポジター連鎖、流出連鎖、自己終端状態、関係証拠が未順序の同一欄に混在していました。後続モデルでは、主役アクター、順序付き有向連鎖、自己終端配置、およびyogaにおける全参加惑星を明確に分離しました。原入力版のAJYグラフにおいて出典namespaceおよびトポロジーキーを明示的に翻訳・投影したところ、313のperson-ruleリンクが復元されましたが（訂正入力版での同診断では309リンク）、身体的遂行における変化は0名から1名にとどまりました。

入力訂正データから再生成されたAJYグラフは、保存アーカイブと完全なコンテキスト一致を示しました。修復された表現では、881本の流入ディスポジターパス、流出パス、62名の自己終端配置、および226名の循環的依存（cycle）が個別の型として保持されています。741規則×420名の計311,220セルにおいて、過去の判定結果を「厳密一致」（旧8,076件の合致中2,952件）、「明示的キー投影一致」（145件）、および「既知の不一致または意味未解決」に分類しました。未解決述語は安易にFALSEへ丸め込まず、未解決のまま保持されています。4つの保存状態すべてで非空の人物集合が不変であった規則は158存在しますが、これはリファクタリングに対する表現の安定性を示すものであり、158の法則の独立した実証を意味するものではありません。

## 3. 選択効果の検証と訓練フォールド限定選択による内部評価

過去のワークフローにおける選択バイアスを評価するため、有限選択パイプライン（AIU → AIV → AIX → AIY）をビットマスクから再構成し、786リード、741規則、および全採用枝を完全再現しました。311名群および109名群の資料作成経路クラスタ内で人物の11機能プロファイルを組ごと999回置換した対照実験では、アルゴリズムが選択した規則数の中央値は782（範囲：690〜870）であり、実データの741規則と拮抗しました。五主面の同面片側参考p値は .605, .115, .920, .598, .429 となりました。全66面における標準化最大差の参考p値は .958 であり、非標準化最大リスク差は p = .034（信仰関連機能の露出4名、全員記録ありという極小面で観測）でした。両統計量は記述的基準として保持されています。

続いて、修復された型付きグラフ（有向パス、流入影響、アクター能力を統合）から構築された別の有限クエリ群について、厳密な5分割交差検証を実施しました。本プロトコルでは、候補生成および候補選択を訓練フォールド内に厳密に限定し、選択されたクエリの適用と両体系集約を評価用テストフォールド側で実行しました。テスト側の活動ラベルを反転させても訓練内の選択が変化しないこと、およびテストフォールドにしか存在しない候補が混入しないことを実検査により確認済みです。ただし、基礎となる文法・語彙の設計史が420名全体を参照して構築された経緯を持つため、本検証は未知の人物に対する完全な外部確認ではなく、選択漏洩を遮断した内部評価として位置づけられます。

本検証では、活動側の評価エンドポイントとして2種類を用いました。第1は台帳上に該当する「活動記録あり」であり、第2は過去の記録においてコンポーネントと機能エッジの「双方でSUPPORTEDと記録されている」状態です。後者は判定基準の厳格さによる影響を調べるための感度分析として設定されたものであり、確定した新たな正解集合を意味するものではありません。また、いずれのエンドポイントにおいても、記録が存在しないことはその人物が生涯を通じてその活動を行わなかったこと（実際の陰性）を証明するものではありません。

11機能 × 6グラフ面 × 2記録エンドポイントの計132面において、選択アルゴリズムを毎回再実行する199回の置換対照を実施した結果、全132面を通じた最大標準化差の参考p値は .785 となり、多重探索全体としては帰無仮説の変動範囲内にとどまりました。

## 4. 局所的観測と組合せ論的疎（Sparsity）

全体としての標準化評価が帰無仮説の範囲内を示す一方で、内部評価のテストフォールド（OOF）において特定の局所的偏りが観測されました：
- **身体的遂行（Jyotish-any）**：テストフォールド37名中13名に記録（非調整の出現差 +15.29pt、同面局所参考 p = .025、全132面補正後 p = .785）。
- **集団実現（両体系・旧二層SUPPORTED記録）**：テストフォールド9名中8名に記録（非調整の出現差 +33.90pt、同面局所参考 p = .010、全132面補正後 p = .860）。
- **身体的遂行および技術実装（両体系主面）**：今回のテストフォールド露出数は0名（該当者なし）。

これらの局所的な偏りは、今回の有限クエリ表現と訓練内選択アルゴリズムの組み合わせによって得られた具体的な測定結果です。これらを後知恵で取り出して確定法則や唯一の仮説として持ち上げることはしません。同時に、両体系主面において露出が0名となった現象は、有限標本において複数の厳密な複合条件を掛け合わせた際に生じるトポロジー的・組合せ論的な「極度の疎（Sparsity）」を反映したものであり、伝統的体系そのものの全否定を意味するものではありません。

## 5. 活動測定、出典テキスト、および資料量交絡の検証

活動測定の基盤として、1,594のコンポーネント-機能リンクに紐づく4,306件の引用参照を保存ハッシュと照合しました。109名の資料経路コホートにおける3,002,408文字のテキスト本文を、過去の改訂を反映した採用版ハッシュと完全一致させ復元しました。

コンポーネント状態と機能エッジ状態が乖離していた50件について、復元された文脈に基づく重点レビューを実施しました。このうち48件は過去の解析にOUTPUTエッジとして含まれていたものであり、残り2件は解析対象外のオーバーレイ要素です。精査の結果は以下の通りです：
- **28件**：本人に直接帰属する具体的行為を支持；
- **12件**：社会的機能の境界定義において曖昧さが残存；
- **7件**：公式な役職や肩書は確認できるものの、実質的な実務・活動範囲が引用から特定不能；
- **1件**：行為の本人帰属が伝記上争われている事例；
- **2件**：解析対象外のオーバーレイ要素。

この50件の根拠対応を完了し、未解決点を明示しましたが、凍結済みの解析ラベルを結果を見て事後的に変更することはありませんでした。また、全1,594件に及ぶ独立した人間による再判定は実施していません。本精査により、過去の `PARTIAL` 判定には「証拠不足」だけでなく、「活動期間の短さ」や「副次的活動」を理由とした格下げが混在していたことが明確になりました。修復された枠組みでは、行為主体性、機能適合度、証拠充足度、活動の主要性、および継続期間を独立した軸として記録します。なお、記録が存在しないことは、その人物が生涯においてその活動を行わなかったこと（陰性）を意味しません。

本文全体が揃う410名において、資料文字数と記録機能数のSpearmanの順位相関係数 $\rho$ は .267（301名群で $\rho = .192$、109名群で $\rho = .303$）でした。一方、資料文字数とグラフ関係数は $\rho = -.064$、パス数は $\rho = -.018$、関係数と記録機能数は $\rho = -.082$ でした。これらは本データセットにおける記述的相関を記録したものであり、統計的独立性やあらゆる交絡の不存在を証明するものではありません。なお、全文入力に含まれなかった311群の残り10名についても、先行修復段階で採取された正確な引用スパンが保存されています。

## 6. 公開資材とスタンドアロン再現手順

過去のv1〜v7リリースはGitHub（`AETHER-CORE1219/Genesis-Core-route-research-public`）上にそのまま維持され、新たに `research_update_20261101/` ディレクトリが追加されます：
- 英日両言語による完全な研究説明文書（`README.md` および `README_JA.md`）
- `data/historical_selection_input.json.gz` および `data/repaired_chain_input.json.gz`：氏名、生年月日・時刻、地理座標、内部IDマッピングを排除し、不可視の通し番号を用いた接続行列、活動プロファイル、クラスタ・フォールド情報
- `scripts/reproduce.py`：Python標準ライブラリのみで動作し、過去の741規則選択（999回置換）、5分割内の候補選択、および199回の置換対照を入力から再実行するスクリプト
- `EXPECTED_REPLAY_RESULTS.json`、集計データ、およびチェックサムファイル

検証者はリポジトリルートから以下のコマンドを実行できます：
```bash
python research_update_20261101/scripts/reproduce.py
```
外部ライブラリのインストールは一切不要です。本スクリプトにより、事前に抽出された接続データからルール選択アルゴリズムの機械的挙動、置換基準、および交差検証の計算プロセスを誰でも手元の環境で独立して再実行・検証できます。この有限な選択手順の再現は、生の出生情報からチャートや活動ラベル全体を再生成する工程とは区別されます。

出生図構造を有向かつ型付きの表現へと修復し、候補選択を交差検証の訓練フォールド内に厳密に隔離することによって、本アップデートは、多重な歴史的占星術の概念が現代的なデータパイプラインと対峙した際にいかなる振る舞いを示すのかを客観的に評価するための堅牢な基盤を提供します。
