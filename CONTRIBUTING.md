# Contributing and reporting problems

This repository is a fixed public research record as well as a working documentation surface. Corrections, reproduction reports, and methodological criticism are welcome. Changes to frozen results require a new versioned research surface; they are not silently applied to an earlier release.

## Open an issue for

- a reproduction success or failure;
- a broken command, checksum, or link;
- a question about an estimator, test family, or claim boundary;
- a documented problem in public source provenance;
- an English or Japanese documentation correction;
- a proposed independent replication design.

## Include in a reproduction report

- repository commit or release tag;
- operating system;
- Python and NumPy versions;
- exact command used;
- exit code and final output;
- whether the checkout preserved LF line endings;
- any local modification made before the run.

Do not post private birth records, personal contact information, API keys, unpublished identity mappings, or copyrighted source text in an issue. Link to lawful public sources when discussing provenance.

## Research-change policy

Documentation corrections may clarify an existing claim without changing the underlying result. A change to people, outcomes, chart classifications, candidate definitions, thresholds, model specifications, or inferential rules must be released as a new research version with its own data projection, result file, claim boundary, and checksum manifest.

Questions can also be sent to [takatsusora@aether-core.org](mailto:takatsusora@aether-core.org).
