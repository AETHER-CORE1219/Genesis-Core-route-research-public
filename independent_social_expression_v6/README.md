# Astrological Social-Expression Route Research v6

This release synthesizes the fixed development420 findings, a corrected five-function meaning-family atlas, person-level traces, and the three public external stress tests from v3-v5.

The strongest defensible conclusion is narrow:

> Fixed development evidence contains repeated, person-traceable astrology-to-social-function structures across five non-exclusive functions. Three external stress tests constrain three particular candidate aggregations or branches, but do not externally validate the remaining families and do not establish astrology as a whole as either confirmed or absent.

Development results range from 1.31x to 3.02x descriptive enrichment. The corrected atlas contains 136 meaning families, 134 supported in both internal development subcohorts. These are development structures, not 136 externally validated routes.

The key methodological result is about granularity: heterogeneous ANY aggregation was too broad, while one exact all-condition branch was too narrow. The minimum defensible future route unit is a finite, meaning-coherent mechanism family with predeclared alternative relation and carrier branches.
